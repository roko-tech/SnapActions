# Screenshot sources

These images use synthetic example text and isolated preferences. The translation image was refreshed for v2.5.0; the toolbar and Settings images are from v2.4.3.

- `selection-toolbar.png`: the production WPF toolbar and actions above a selected sentence in a small native demonstration window. The fixture supplies the selection directly; this image demonstrates presentation, not automatic capture.
- `inline-translation.png`: two English lines' Arabic translation in the production translation card (dark theme, editable selection), captured from its window on Windows at 250% scaling. An isolated harness supplied the synthetic selection; the translation came from Google's live page.
- `settings.png`: the production Settings window rendered by the compiled WPF package check in the light theme.

No user desktop, browser tabs, account information or personal selections are included.
