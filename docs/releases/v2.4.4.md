# SnapActions v2.4.4 — Multiline selection and a smaller popup

This update repairs the native Chromium selection fallback used by apps such as Codex and makes inline translation more compact.

- Preserve complete selections across explicit line breaks and wrapped lines when the native selection agrees with both ends of the drag. Retain the selected text, punctuation and line breaks without rebuilding it from a horizontal strip.
- Keep the existing single-line Arabic/English capture correction and reject stale or mismatched native ranges.
- Correct a verified Chromium defect that reports an Arabic line break before its sentence. Reordering requires an exact match to the enclosing text and its visible endpoint lines; no characters may be added or removed.
- Reduce the translation popup from 520 × 620 to **440 × 440** device-independent pixels, with the page at **80% zoom**. Resize it from the lower-right corner or scroll for longer text.

Translation stays inline through Google Translate. The 500 UTF-8 byte limit, online-lookup consent and default of eight inline actions remain unchanged. Existing saved preferences are preserved.

Some partial Arabic selections still expose inconsistent character boundaries through Windows accessibility. These are rejected instead of returning the wrong text. The optional browser companion avoids that native fallback in supported browsers; other apps can use the existing explicit-copy capture option.

## Live validation

On Windows 10 at 250% scaling, selecting two English lines in Codex displayed the automatic toolbar and opened both complete lines with their Arabic translation in the compact popup. Synthetic native Chromium checks also covered wrapped text, adjacent paragraphs, a blank middle line, full Arabic selections in both directions, and full and partial mixed Arabic/English selections. The popup's scroll controls exposed the remaining result controls.

The published release includes `release-validation.json` for package identity, automated checks, hosted CI and installation verification, and `live-validation.json` for reviewed local observations. These checks cover the recorded scenarios, not every application's accessibility implementation.

## Upgrade

Exit SnapActions and replace the complete application folder contents with the new ZIP. Keep the executable and accompanying files together. Reload the optional browser companion after replacing its files; register it again only if the executable moved.
