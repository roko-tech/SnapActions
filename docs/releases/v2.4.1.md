# SnapActions v2.4.1 — toolbar customization

Historical status: built and installed locally on September 7, 2026. This version was not published separately; its changes are included in [v2.4.2](v2.4.2.md).

## Changes

- Removed QR Code and Inspect Text, including the QR generator/decoder dependencies, window, icon and package notice. Settings migration prunes their retired IDs while preserving other pins.
- Drag an action from a submenu, overflow menu or the toolbar's action catalog onto the toolbar to pin it. Drop on either half of an existing pin to insert before or after it; a blue line marks the position. Disabled pins can still be dragged using their containing toolbar.
- Right-click an action to pin, unpin, hide, or move it. The toolbar gear lists every action, including hidden actions that can be restored. Hiding preserves the saved pin position.
- Pinned actions are independent of the suggested-action limit and category-menu visibility. Pins that do not apply to a selection remain visible but disabled, with an explanatory tooltip. Per-app hidden-action rules still apply.
- Settings changes refresh the existing toolbar and open action lists. Refresh waits until a drag or context-menu interaction finishes. The original selection's app remains the source for per-app rules.
- Removed the fixed 600-DIP width ceiling. The toolbar uses the active monitor's available width; any remaining overflow stays in More. The old max-inline setting is now labeled **Suggested actions on toolbar** to distinguish it from pins.

The inspected user settings already contained an inline limit of 8. The browser and native paths use one desktop toolbar and the same settings object; there was no separate browser limit of 4. The fixed width budget and removal of Paste/Delete from read-only selections could make the toolbar appear unchanged.
