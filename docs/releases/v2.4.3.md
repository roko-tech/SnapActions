# SnapActions v2.4.3 — Google Translate inside the popup

Translate now displays Google Translate's normal website inside a dedicated SnapActions popup. It replaces the MyMemory request path that repeatedly exceeded the app's eight-second timeout. Translation stays inside SnapActions; no external browser tab is opened.

## Changes

- Use Google's visible language, swap, text-editing and copy controls, initialized with the selection and saved language choices. The popup provides Close and page-load Retry.
- Keep the initial selection limit at **500 UTF-8 bytes** and require online-lookup consent before sending selected text and languages to Google.
- Default new settings to **8 inline suggested actions**. Existing saved values and pinned actions are preserved.
- Replace the long README with a simpler overview and a separate [user guide](../user-guide.md).
- Keep the popup header and Close button visible on the tested high-DPI display by using software rendering for this window's native WPF surface.

## Requirements and limits

Inline translation requires internet access and the [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). The desktop app's .NET runtime remains bundled. No paid translation API or account configuration is required.

Google controls the page, translation timing and results. Website outages, network restrictions and page changes can affect this feature. SnapActions does not promise a fixed translation latency or cache translated results itself. Offline models and unofficial translation endpoints are not bundled.

Read the [investigation and implementation notes](../translation-fix-2026-09-08.md) for the measured failure, alternatives considered and evidence limits.

## Validation

Final local source/package checks passed: **545 .NET tests, 12 browser-companion tests, 11 WPF checks and 3 native-host checks**. Live popup captures verified Arabic→English, French→English and mixed Unicode translation in **2.824–8.325 seconds**. A 492-byte selection was fully translated by **3.827 seconds**, with its result below the initial viewport. These sampled timings are not latency guarantees.

Live checks also verified Copy, language swapping, Arabic text editing, scrolling long results, native Retry after HTTP 503, the 10-second page-load deadline, and replacement of a popup while its old request was pending.

See the release attachments `live-validation.json` for reviewed local observations and `release-validation.json` for source identity, hosted CI, package identity and installation verification. The local checks do not certify those later release steps.

## Upgrade

Exit SnapActions, extract the complete new ZIP and keep its executable and accompanying files together. Saved settings are retained. Reload the optional browser companion after replacing its files; register it again only if the executable moved. The companion protocol remains version 1.
